# YouTube Video Summarizer - Get AI Summaries of Any YouTube Video!

Hey! I built a Chrome extension that summarizes YouTube videos with AI. Want to try it?

## Install in 3 Steps:

### Step 1: Download
Click here and download the ZIP file:
👉 **https://github.com/travislima/youtube-summarize/archive/refs/heads/claude/init-project-011CUPtbJtTXPSUcipiicHbo.zip**

Then extract/unzip the file to a folder on your computer.

### Step 2: Install in Chrome
1. Copy and paste this into Chrome's address bar: `chrome://extensions`
2. Turn ON "Developer mode" (toggle in top right)
3. Click "Load unpacked" button
4. Select the **`extension`** folder from the unzipped files
5. Done! ✅

### Step 3: Use It!
1. Go to any YouTube video (one with captions/CC)
2. Look for the "Summarize" button below the video (next to Like/Share)
3. Click it and wait ~10 seconds
4. Get an AI-generated summary with timestamps!

## What It Does:
- Extracts video transcript automatically
- Creates smart summaries with key points
- Shows timestamps so you can jump to important parts
- Answers the question in the video title directly

## Having Issues?
- Make sure the video has captions (click CC button to check)
- If button doesn't show up, refresh the page
- Still stuck? Message me!

Enjoy! 🚀
