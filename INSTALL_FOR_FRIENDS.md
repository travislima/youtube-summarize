# YouTube Video Summarizer - Installation Guide for Friends

Hey! Thanks for testing this YouTube summarizer extension. Here's how to install it:

## Installation Steps

### 1. Download the Extension
- Go to: https://github.com/travislima/youtube-summarize
- Click the green "Code" button
- Select "Download ZIP"
- Extract the ZIP file to a folder on your computer

### 2. Install in Chrome
1. Open Chrome and go to: `chrome://extensions`
2. Toggle ON "Developer mode" (top right corner)
3. Click "Load unpacked"
4. Navigate to the extracted folder and select the **`extension`** folder inside
5. The extension should now appear in your extensions list!

### 3. Use It!
1. Go to any YouTube video
2. Wait for the "Summarize" button to appear below the video (next to Like/Share buttons)
3. Click "Summarize"
4. Wait 5-10 seconds for the AI summary to appear!

## Notes
- The video must have captions/transcripts enabled
- The extension works on any YouTube video with English captions
- Summaries include timestamps and key points

## Troubleshooting

**Button doesn't appear?**
- Refresh the page
- Make sure the video has captions (click the CC button to check)

**"No transcript found" error?**
- The video doesn't have captions enabled
- Try a different video

**Still not working?**
- Open Chrome DevTools (F12)
- Go to Console tab
- Screenshot any errors and send them to me
